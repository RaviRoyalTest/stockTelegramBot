🔑 Gmail setup (once, 2 min)

  1. Google Account → Security → turn ON 2-Step Verification.
  2. Search App passwords → create one for Mail → copy the 16-letter code.
  3. On the host set SMTP_HOST=smtp.gmail.com, SMTP_PORT=587, SMTP_USER=you@gmail.com, SMTP_PASS=<16-letter code>.

The login password will NOT work — it must be the App Password (spaces are stripped automatically). Easier alternative: set RESEND_API_KEY from resend.com and skip SMTP entirely. Optional polish: EMAIL_SUBJECT_PREFIX + EMAIL_FROM_NAME.
